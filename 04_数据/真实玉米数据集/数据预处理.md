# 流程文档：从 VCF 到深度学习特征矩阵 ()

本文档详细归纳了从原始 VCF 基因型文件和时序表型数据中，通过严格质控 (QC)、连锁不平衡 (LD) 剪枝、高级表型特征工程（含非线性特征提取与正态变换）、PCA 群体结构校正的 GWAS 筛选，最终导出一个可用于深度学习的 **012 格式特征矩阵** 的完整步骤。

## 流程概览

1.  **步骤 1：基因型数据清洗与降维 (PLINK 2)**
	- **目标**：去除低质量位点，重命名 ID，去除高度连锁冗余位点，将数据量从上亿级压缩至几十万级，并保存为二进制中间文件。
	- **输入**：`merge.nonCTG.gt.400.vcf.gz`
	- **输出**：`data_qc_ld_pruned` (.pgen/.pvar/.psam)
2.  **步骤 2：基于 GWAS 的特征筛选 (R 语言)**
	- **目标**：结合时序表型数据，通过统计学方法（PCA校正 + Min-P 策略 + 高级特征工程）筛选出与性状最相关的 Top N 个 SNP。
	- **核心算法**：自动解析非等间距时间点、计算 Slope/AUC/Mean、应用 RINT 变换、PCA 校正。
	- **输入**：`r_input_data.bed` (由步骤 1 转换而来), `phenotypes_csv/`
	- **输出**：`top_snps_list.txt`
3.  **步骤 3：生成最终矩阵 (PLINK 2)**
	- **目标**：从 LD 剪枝后的数据中提取筛选出的 SNP，导出为深度学习模型所需的 012 数值矩阵。
	- **输入**：`data_qc_ld_pruned`, `top_snps_list.txt`
	- **输出**：`final_dl_dataset.raw`

## 步骤 1: 基因型数据预处理 (PLINK 2)

**目标：** 对原始VCF进行质控、重命名，并进行LD剪枝，得到用于GWAS分析的独立SNP集。

**工具：** `plink2` (Linux 命令行)

### 1.1 严格质控 (QC)

从原始VCF文件开始，进行严格的质控。

```bash
# ==========================================
# 第一步：基础QC、重命名ID并转换为 PGEN 格式
# ==========================================

# --vcf:                   原始 VCF 文件输入
# --set-all-var-ids '@_#': 重命名 SNP ID 为 "染色体_位置" 格式 (例如: 1_12345)
# --rm-dup exclude-all:    去除重复 ID 或重复位置的位点，防止后续报错
# --snps-only just-acgt:   仅保留 A/C/G/T 的 SNP，去除 Indel 和结构变异
# --max-alleles 2:         仅保留二等位基因 (Biallelic)
# --geno 0.05:             剔除缺失率 > 5% 的 SNP (严格筛选)
# --maf 0.05:              剔除最小等位基因频率 < 5% 的 SNP (严格去除稀有变异)
# --hwe 1e-6:              剔除不符合哈代-温伯格平衡的位点 (p < 1e-6)
# --make-pgen:             输出为高效的 PLINK 2 二进制格式 (.pgen/.pvar/.psam)
# --out:                   输出文件前缀

plink2 --vcf ../../plink/merge.nonCTG.gt.400.vcf.gz \
       --set-all-var-ids '@_#' \
       --rm-dup exclude-all \
       --snps-only just-acgt \
       --max-alleles 2 \
       --geno 0.05 \
       --maf 0.05 \
       --hwe 1e-6 \
       --make-pgen \
       --threads 8 \
       --out data_qc_strict
```
* **产出:** `data_qc_strict.pgen`, `.psam`, `.pvar`

### 1.2 连锁不平衡 (LD) 剪枝

在质控后的数据上进行LD Pruning，以移除冗余的SNP。

```bash
# ==========================================
# 第二步：连锁不平衡 (LD) 剪枝计算
# ==========================================

# --pfile:                 读取上一步生成的清洗后数据
# --indep-pairwise:        计算 LD。参数含义：窗口大小100kb，步长1，r^2阈值0.2
# --out:                   输出包含建议保留/剔除位点列表的文件 (.prune.in / .prune.out)

plink2 --pfile data_qc_strict \
       --indep-pairwise 100kb 1 0.2 \
       --threads 8 \
       --out ld_pruned
```
* **产出:** `ld_pruned.prune.in` (保留的SNP列表), `ld_pruned.prune.out` (移除的SNP列表)

### 1.3 保存 LD 筛选后的数据

```bash
# ==========================================
# 第三步：保存 LD 筛选后的数据
# ==========================================
# 我们先生成一个二进制的中间文件 (data_qc_ld_pruned)，这才是后续 GWAS 的输入
# --extract:               仅提取第二步生成的 .prune.in 文件中的位点
# --make-pgen:             保存为二进制 PLINK2 格式 (本地保存)

plink2 --pfile data_qc_strict \
       --extract ld_pruned.prune.in \
       --make-pgen \
       --threads 8 \
       --out data_ld_pruned
```

### 1.4  提取独立位点并导出为 012 格式

```bash
# ==========================================
# 第四步：提取独立位点并导出为 012 格式
# ==========================================

# --pfile:                 读取LD减枝后的文件
# --extract:               仅提取第二步生成的 .prune.in 文件中的位点 (即相互独立的SNP)
# --export A:              导出为 0/1/2 数值矩阵 (.raw 文件)。A 代表 Additive (加性模型)
# --out:                   最终输出文件前缀

plink2 --pfile data_ld_pruned \
       --export A \
       --threads 8 \
       --out data_plink_snp
```
